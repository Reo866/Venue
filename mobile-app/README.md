# Venue Mobile App

Expo tabanlı React Native uygulaması.

## Özellikler

- Türkçe onboarding ve tercih kalıcılığı
- Keşif, deneyim, etkinlik, mesajlaşma akışları
- Konum tabanlı öneri altyapısı (API entegrasyonuna hazır)
- Push bildirim modülü (Expo Notifications entegrasyonuna hazır)

## Çalıştırma

```bash
npm install
npm run dev
```
