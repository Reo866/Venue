# Venue (LOCALS)

Bu depo, Venue (kod adı: LOCALS) sosyal deneyim platformu için üretime hazır çoklu proje yapısını içerir.

## Projeler

- `mobile-app`: Expo + React Native mobil uygulama.
- `backend`: Node.js + Express + TypeScript API + Socket.IO.
- `admin-panel`: React + TailwindCSS yönetim paneli.
- `seed-scripts`: KKTC odaklı büyük ölçekli örnek veri üretimi.
- `logos`: Venue marka kimliği için SVG logo seti.

## Hızlı Başlangıç

Her proje klasöründe:

```bash
npm install
npm run dev
```

Detaylı kurulum yönergeleri alt proje README dosyalarında yer alır.
